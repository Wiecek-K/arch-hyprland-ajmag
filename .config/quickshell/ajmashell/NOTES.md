## Rules

The code review checks these (`docs/agents/delivery.md` in the project). Read them before any Ajmashell edit.

- **Style only from `singletons/theme/Theme.qml`** (`import qs.singletons.theme`): `Theme.colors.<matugen name>` (snake_case, e.g. `Theme.colors.on_surface`, all 50 Material 3 roles), `Theme.font`, `Theme.spacing`, `Theme.radius`, `Theme.bar`. Transparent = `Theme.transparent` (one variable for every helper window and empty state; never tint it); a tint for the whole Bar goes into `Theme.bar.background` only. No colour/font literals in components (`~/Projects/hyprland-lua-migration/tools/test-theme.sh` checks it). Donor components: replace their theme references with `Theme`.
- **Bar look and layout** (ADR 0002): no full background — each element in its own fully rounded island (like Waybar's modules). Left: tray; centre: media (gap to the clock = 2/3 of the clock island's width), clock (centred on the monitor's axis), workspaces to its right (one list shared by all monitors; the focused one is a full circle); right: output volume, mic, a separator (`bar/Separator.qml`, Waybar's dot-line glyph), then one pill with BT, Wi-Fi and bell at the right edge (`bar/IslandGroup.qml`, islands inside have `grouped: true`; bell: LPM opens the Centrum sterowania, PPM toggles silent mode). No power button on the Bar (it lives in Centrum sterowania). Tray and volume swapped sides in ticket 17 (user, 2026-10-07).
- Size and position of an element must not depend on its state (focused, hovered…): draw the state as a background layer and round positions to whole pixels, otherwise text jumps when the state changes. Check with before/after `grim` screenshots.
- Quickshell reloads on every save: change a file in one write, not in several `sed` steps (a half-edited file shows reload errors in `qs log`).
- Keep pure logic in a JS module next to the component (`bar/workspaces.mjs`, `bar/audio.mjs`; shared wheel accumulator `bar/wheel.mjs`; imported as `import "workspaces.mjs" as Logic`) and test it with node: `node --test ~/Projects/hyprland-lua-migration/tools/test-bar-*.mjs`.
- **Do not run `shellset.sh restart` (or `qs kill`) right after saving a QML file.** Twice (2026-10-01) the old `qs` logged "Exiting due to IPC request" in the middle of a hot reload, did not exit and kept running with no windows — the Bar disappeared and no new instance started. Wait ~6 s after the last save; if it happens: `pkill -x qs` (then `-9`), `shellset.sh start ajmashell` (`restart` would start Waybar, because `active` already reports no Ajmashell).
- Create a new component file before saving the file that uses it: when the use came first, the hot reload failed ("X is not a type") and the watcher did not reload once the file appeared — `touch` the user file to reload (2026-10-07).
- The Bar is on `WlrLayer.Top` on purpose (ticket 13): on Bottom every frame of the Bar or its popup made Hyprland redraw the whole monitor (blur invalidation, hyprwm/Hyprland#6830).
- Start apps from the shell through Hyprland (`Hyprland.dispatch(Logic.execRequest(…))` → `hl.dsp.exec_cmd`), not `execDetached`: with `misc:initial_workspace_tracking = 2` children of `qs` inherit the shell's `HL_INITIAL_WORKSPACE_TOKEN` and open on the workspace where the shell started. (The Bar's nm-connection-editor / blueman still use `execDetached`.)
- **Prototype stage (2026-10):** look values (alphas, sizes, colours) were picked in quick tests with the user and will change in a later styling pass. Restyling = edit `Theme.qml` (header comment lists the rules) + blur rules in `rules.lua`; record each change in `pochodzenie-komponentow.md` („Zmiany” of the component's entry). Verify on the live shell with a `grim` screenshot; wait ~6 s after the save before any restart.

## Gotchas: Qt, Quickshell, Hyprland

Read when a change behaves oddly or touches the named API.

- QML: a property named `on` + capital letter (`onSurface`) is read as a signal handler → keep snake_case colour names.
- Singletons load lazily and `FileView` reads asynchronously; `Theme.qml` forces one blocking read at start. `FileView` watches the parent directory, which must exist when the shell starts.
- Hyprland focus across monitors: switching to a workspace on the other monitor sends `focusedmon>>MON,OLD_WS` and only then `workspace>>NEW_WS`, so `Hyprland.focusedWorkspace` is briefly the old one. Show focus through a short settle timer (`Theme.motion.settle`), see `bar/Workspaces.qml`. The same for the workspace list: Quickshell removes a destroyed workspace at once but adds a new one only after re-reading the list, so bind the list through the settle timer too.
- Mouse wheel on the Bar: use `MouseArea { acceptedButtons: Qt.NoButton; onWheel: … }` — `WheelHandler` gets no wheel events on the layer-shell window (tested 2026-09-29). Test input without the user: cursor via `hyprctl dispatch 'hl.dsp.cursor.move({ x = …, y = … })'`, wheel via a virtual uinput mouse (the user has an ACL on `/dev/uinput`; python ctypes, no extra packages).
- A reload may keep the old copy of an edited `.mjs` module (seen 2026-10-01: changed icon in `bar/connectivity.mjs` stayed old after "Configuration Loaded"). After editing a `.mjs`, check the Bar with a `grim` screenshot; if it is stale, restart the shell. The same for new `Theme` style properties: after adding `backgroundTinted` (2026-10-08) the hot reload updated the Orbita but the Centrum sterowania kept the old grey until a full restart — check every popup that uses the change, not only one.
- Group style values in inline `component X: QtObject {}` types, not `property QtObject` — otherwise qmllint/qmlls do not see the members.
- PipeWire (`Quickshell.Services.Pipewire`): bind the node with `PwObjectTracker { objects: [node] }`, otherwise `audio` and `properties` stay empty. Volume above 100% is not clamped — clamp it yourself (`bar/audio.mjs`, limit 150%). The node has no active port, so jack headphones look like the speaker (accepted, ADR 0002). Both audio islands are one component: `bar/Volume.qml` (sink) and `Volume { microphone: true }` (default source) — change behaviour there once, not per island.
- Nerd Font icons overhang their `advanceWidth`: a fixed icon slot must also use `FontMetrics.tightBoundingRect(glyph).width`, or the icon overlaps the next text (`bar/Volume.qml`). Text that must keep its width: pad it to a fixed number of characters (the Bar font is monospace).
- `HyprlandFocusGrab` refuses a window that is not mapped yet: set `active` with `Qt.callLater` after the popup becomes visible, not `active: popup.visible`.
- Icon theme for tray icons: `//@ pragma IconTheme Ajmashell-Dark` in `shell.qml` (symlink to the folder-colour overlay, see Theming) (Qt 6 has no theme otherwise; `QT_QPA_PLATFORMTHEME=qt5ct` is Qt 5 only). Pragmas need a full restart (`qs kill -c ajmashell; setsid -f qs -c ajmashell -n -d`), not a reload. A save that leaves the file broken may also need a restart: the watcher sometimes misses the fix.
- Hyprland dispatch from QML: Lua only, e.g. `Hyprland.dispatch("hl.dsp.focus({ workspace = 3 })")`; build the strings with `focusRequest` / `luaValue` from `bar/workspaces.mjs` (they escape strings).
- A window built on every open is slow: `LazyLoader { active: open }` recreated the carousel window each time (new scene graph, shaders, textures, delegates) and the GUI thread stalled 134 + 242 ms, so the fade-in jumped to the end. For overlays opened often, create once (`active: true`) and toggle `visible`; reset state in `onVisibleChanged`. A hidden window has no size — compute sizes from `screen.width/height`, or every delegate counts as on screen and loads (421 MB RSS seen). See `wallpaper/WallpaperPicker.qml`.
- Animations need a value to start from: a `Behavior` animates only when the property changes while the item is shown. For a fade on every open, set the target to 0 when hiding and back to 1 after showing (`Qt.callLater`), and do not let it reach 1 while hidden (`settled = visible`).
- Nested `TapHandler`s both fire: a button inside a clickable row also triggers the row's handler. Check the tap position in the outer one (`control/ConnectionRow.qml`).
- Qt's JS engine returned `{}` from `ids.forEach((id, i) => obj[id] = f(lines[i]))` inside an `.mjs` (2026-10-09, `power.mjs`; node passed). Fill objects with a plain `for` loop and check `.mjs` results in the running shell, not only in node.
- Popup position from `item.mapToItem(null, …)` inside a binding is not updated when the item moves (only on the properties the binding reads), so it keeps the value from before the Bar was laid out. Compute such offsets when the popup opens (`MediaPopup.qml`, `AudioPopup.qml` `shift`).
- Launcher surface is only box-sized (no anchors), keyboard `WlrKeyboardFocus.OnDemand` + `HyprlandFocusGrab` armed after the window shows; `Exclusive` breaks the grab (clicks beside the box go to the layer).
- Qt's JS engine has no object spread: `{ ...a }` in an `.mjs` fails the whole shell at load (`Unexpected token '...'`, Bar gone; node tests pass). Use `Object.assign({}, a)`; for arrays prefer `concat`.
- In `onXChanged`, other bindings that depend on X may still hold the old value (seen 2026-10-03: `calcMode` in `onQueryChanged`). Compute from X itself inside the handler.
- A `Process` whose binary is missing emits neither `started` nor `exited`, only `running` → false. Detect it with a `started` flag in `onRunningChanged` (`launcher/Launcher.qml`, qalc).
- Blur under shell windows: Hyprland `hl.layer_rule` per namespace in `hypr/configs/rules.lua` (`ajmashell-launcher`, `ajmashell-bar`, `ignore_alpha = 0.5` so fully transparent parts stay sharp). A new shell window that should blur needs its own rule. **`ignore_alpha` is a threshold:** a background with alpha below it (e.g. `Theme.launcher.background` set to 0.4) gets no blur at all — lower `ignore_alpha` with it.
- Qt's JS engine (V4) in `.mjs` modules: no `Object.fromEntries`, avoid object spread `{ ...o }` — node tests pass, the shell logs "Type error" (ticket 42). Write plain loops / explicit fields.
- An `id` equal to a property name of the root object (e.g. `id: month` next to `property int month`) shadows the property inside the file: `month = …` then fails with "left-hand side of assignment operator is not an lvalue" (ticket 42).
- A new inline `component` in `Theme.qml` or a new `.qml` file used by an existing one: the hot reload fails with "X is not a type"; restart the shell (after the ~6 s wait).

## Testing and lint

All automated checks: `~/Projects/hyprland-lua-migration/tools/check.sh`. Below: manual and live techniques.

Live input without the user: `tools/vmouse.py move|click|wheel|nudge` (uinput mouse; reuse it, do not write a new one). Screenshots for reading: `tools/shot.sh OUT.jpg "X,Y WxH"`.

- Lint with Qt 6: `/usr/lib/qt6/bin/qmllint -I "$(dirname "$(readlink .qmlls.ini)")" -I /usr/lib/qt6/qml <file>` (run in `quickshell/ajmashell/`; `/usr/sbin/qmllint` is Qt 5 and prints nothing, exit 255).
- Testing focus between monitors: under Lua `hyprctl dispatch 'hl.dsp.focus({ monitor = "eDP-1" })'` changes the focused monitor (the old `dispatch focusmonitor eDP-1` fails with a Lua syntax error); `hyprctl dispatch movecursor` does not change focus.
- Hover tests: `hyprctl dispatch 'hl.dsp.cursor.move(…)'` sends no motion to the client, so hover/tooltips keep the old state; follow it with a 1 px relative move from the virtual uinput mouse.
- Test theme logic in a throw-away instance, not the running shell: `qs -p <dir> -n -d` + `qs ipc -p <dir> call …`, colours file overridden with `AJMASHELL_COLORS`.
- Find stalls with timestamps, not screenshots: log `Date.now()` in `onOpacityChanged` (or any animated property) — gaps over 16 ms between steps are dropped frames. `grim` bursts (~300 ms apart) only show the coarse picture.
- Test notifications without touching the user's notification daemon: run a second shell in its own session bus — `dbus-run-session -- bash script.sh`, where the script starts `qs -c ajmashell &`, sends `notify-send …`, calls `qs ipc --pid $QS call …`, takes `grim -o <monitor>` screenshots and kills `qs`. The second Bar shows on screen for the few seconds of the test. Qt's JS engine has no `Array.flatMap` (TypeError at runtime; node tests pass) — use `forEach`/`push` in `.mjs` modules.
- Check an `.mjs` in Qt's JS engine without the shell: a throw-away `t.qml` (`import "x.mjs" as L`, `Component.onCompleted` + `console.warn` + `Qt.quit()`) run with `QT_FORCE_STDERR_LOGGING=1 QT_QPA_PLATFORM=offscreen /usr/lib/qt6/bin/qml t.qml` — without `QT_FORCE_STDERR_LOGGING` the `qml` tool prints nothing (logs go to the journal). Read files with `XMLHttpRequest` + `QML_XHR_ALLOW_FILE_READ=1`.
- `qmllint` reads the generated `qmldir` files in `/run/user/1000/quickshell/vfs/…`, refreshed only on a full shell start: after deleting a QML file it warns "X.qml is listed as component … but does not exist" until a restart. The running shell is fine.
- Synthetic input in tests: `wtype` sends keys to whatever has the keyboard — if the shell surface lost focus, an Escape lands in the user's terminal (in Claude Code it cancels the pending tool call). Prefer a virtual-mouse click or IPC, and check focus first; the user's own cursor moves change the focused monitor mid-test.
- GPU/CPU cost of a popup: `~/Projects/hyprland-lua-migration/tools/measure-gpu.sh LABEL SEC [none|orbit|launcher] [look]` — tell the user first, run in the background (a foreground spinner inflates Hyprland's numbers); needs `sudo -n intel_gpu_top`. Open optimisation ideas: ticket 25 in the project.

## Components

One entry per component: files, IPC, tests, ADR. Read the entry of the component you change.

Pure logic `singletons/barpopups/popups.mjs` (tests `tools/test-bar-popups.mjs`).
